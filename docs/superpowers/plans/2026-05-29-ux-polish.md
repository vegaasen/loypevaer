# UX Polish — Clarity, Navigation & Mobile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish the site's UX across four areas: value proposition clarity, navigation/discoverability, visual hierarchy on event cards, and mobile UX — while keeping the existing visual identity (Playfair/Inter, Norwegian nature palette) intact.

**Architecture:** All changes are within the existing React + CSS custom-properties setup. No new libraries. The search feature moves to the hero and the nav select is supplemented with an "Alle arrangement" text link. Card info hierarchy is adjusted via CSS and minor JSX reorder. Mobile improvements are CSS-only except the filter pill scroll fix.

**Tech Stack:** React 18, TypeScript strict, plain CSS (BEM-ish), Vite, Bun

```tsx
<div className="home-page__hero-search-wrap">
  <input
    type="search"
    className="home-page__hero-search"
    placeholder="Søk etter arrangement…"
    value={search}
    onChange={(e) => setSearch(e.target.value)}

</div>
```

- [ ] **Step 3: Scroll active pill into view on discipline change in `HomePage.tsx`**

Add a `activePillRef` ref and scroll effect. At the top of `HomePage`, add:

```tsx
const activePillRef = useRef<HTMLButtonElement | null>(null);

useEffect(() => {
  activePillRef.current?.scrollIntoView({ behavior: "smooth", inline: "nearest", block: "nearest" });
}, [discipline]);
```

Update the pill button to attach the ref when active:

```tsx
<button
  ref={discipline === d ? activePillRef : null}
  key={d}
  className={`home-page__filter-pill${discipline === d ? " home-page__filter-pill--active" : ""}`}
  onClick={() => setDiscipline(d)}
  aria-pressed={discipline === d}
>
  {FILTER_DISCIPLINE_LABEL[d]}
</button>
```

Note: `useRef` is already imported in `HomePage.tsx`.
